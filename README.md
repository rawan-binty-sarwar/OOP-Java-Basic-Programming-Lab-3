# Java Number System & Conversion Practice

A collection of Java programs focused on binary, decimal, octal, and hexadecimal number systems. The programs also demonstrate basic arithmetic operations, user input, and number conversions.

## Main Concepts
- Binary Arithmetic
- Number System Conversion
- Decimal Conversion
- Octal Conversion
- Hexadecimal Conversion
- Java Scanner Input

**Programming Language:** Java  
**Level:** Beginner  
**Purpose:** Academic Practice
